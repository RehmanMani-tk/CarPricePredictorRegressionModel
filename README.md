A small linear regression project predicting used car prices, the self project was conducted to get familiar with multicolinearity, one-hot encoding and rapidfuzz.
Libraries used are pandas, numpy, matplotlib, seaborn, scikit-learn, rapidfuzz.

Data cleaning includes fixing typos, correcting names, splitting brand and Car name into separate columns.
Data distribution was analyzed, correlation heatmaps were implemented.
Outlier check using the IQR method to flag relative outliers.
One hot encoding for the categorical features.
Linear regression modelling and cross validation.
